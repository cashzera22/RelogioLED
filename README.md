# RelogioLED

Meu primeiro projeto de lógica de programação utilizando Java 8.

## Sobre o projeto

O RelogioLED é um programa desenvolvido para resolver um desafio envolvendo um relógio digital de 7 segmentos.

O programa recebe um horário inicial e os custos de movimentação dos ponteiros. Em seguida, procura horários válidos que diferem do original pela alteração de exatamente um segmento de LED e seleciona aquele com o menor custo total.

## Tecnologias utilizadas

- Java 8
- IntelliJ IDEA

## Conceitos praticados

- Estruturas de repetição
- Estruturas condicionais
- Métodos
- Manipulação de strings
- Operações com bits
- Cálculo de distâncias e custos
- Testes de entrada e saída

## Exemplo de execução

**Entrada:**

```text
02:38
2 5
```

**Saída:**

```text
02:39
```

## Como executar

1. Abra o projeto em uma IDE compatível com Java 8.
2. Abra a classe `RelogioLED`.
3. Execute o método `main`.
4. Informe o horário e os custos solicitados.

## Objetivo

Este projeto faz parte da minha jornada de aprendizado em Java, com foco no desenvolvimento da lógica de programação, na resolução de problemas e na organização de código.
